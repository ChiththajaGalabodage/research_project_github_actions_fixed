# GitHub Actions Fix Steps

This project is updated so the GitHub Actions artifact always includes the updated comparison metrics.

## What was fixed

- `pipeline.yml` now has `workflow_dispatch`, so you can manually run it from the Actions tab.
- The workflow forces deterministic fallback mode by setting `GEMINI_API_KEY: ""` in CI.
- `scripts/compare_methods.py` no longer re-runs the full agent pipeline inside the comparison step. It reuses `tests/test_generated.py` generated by the previous pipeline step.
- Test totals are parsed as `passed + failed + errors + skipped + xfailed + xpassed`.
- `comparison_report.csv` includes all required metrics.
- Pytest output uses `--tb=short` to avoid CI log hangs.
- Dynamic coverage is disabled by default in CI and replaced with a fast static target-function coverage estimate. To enable real coverage locally, run with `ENABLE_DYNAMIC_COVERAGE=1`.

## Push to a new repository

```powershell
git init
git branch -M main
git add .
git commit -m "Fix GitHub Actions comparison artifact pipeline"
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```

## Run manually on GitHub

1. Open the repository on GitHub.
2. Go to **Actions**.
3. Select **AI Test Generator Pipeline**.
4. Click **Run workflow**.
5. After success, download the artifact named `ai-test-generator-artifacts`.
6. Open `reports/comparison_report.csv`.
